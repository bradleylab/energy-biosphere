# Archive

This directory keeps older or non-standard package materials out of the main
repository view while preserving provenance.

- `legacy/biosphere_size_model_v5.ipynb` is the final versioned notebook
  filename before the current notebook was renamed to `biosphere_size_model.ipynb`.
- `source_exports/exoplanet_data.xlsx` is the Excel export corresponding to the
  exoplanet input table. The notebook uses `data/exoplanet_data.csv`.
